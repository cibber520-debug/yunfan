# 云帆志愿 · 极简上线清单（CloudBase）

> 复杂配置已由团队完成（Dockerfile / 配置 / 构建验证），你只需照下面勾选操作。

## 一、你需要提供什么（2 样）
- [ ] 一个腾讯云账号（已开通 CloudBase 能力）
- [ ] （可选）DeepSeek API key —— 没有也能跑，自动降级本地引擎

> 云上资源（环境 / 数据库 / 容器）都是你在控制台开通后系统自动给的，无需提前准备。

## 二、你需要怎么做（3 步）

### A. 控制台开通 4 样（都在 CloudBase 控制台，记下几个值）
- [ ] 一个**环境**（记下 环境 ID）
- [ ] **静态网站托管**（记下域名，形如 `xxx.tcloudbaseapp.com`）
- [ ] **云托管**：建服务 → 选 `server/Dockerfile`、监听端口 `3001`、健康检查 `GET /api/v1/health`
- [ ] **云数据库 PostgreSQL**：建库 `yunfan`（记下 地址 / 账号 / 密码）

### B. 本地跑几条命令
```bash
# 装工具并登录
npm i -g @cloudbase/cli && tcb login

# 构建并上传前端
pnpm build && tcb hosting deploy dist -e <环境ID>

# 初始化数据库（把 <> 换成第 A 步记下的云 PG 信息）
PGHOST=<地址> PGUSER=<账号> PGPASSWORD=<密码> PGDATABASE=yunfan bash deploy/init-db.sh
```

### C. 云托管里填环境变量并部署
- [ ] 把 `deploy/backend-env.example` 里的变量照抄进云托管「环境变量」，重点：
  - `DATA_SOURCE=postgres`
  - `CORS_ORIGIN=<静态站域名>`（与前端互为白名单）
  - `AUTH_SESSION_SECRET` / `AUTH_CODE_PEPPER`：用下方命令各生成一次粘贴（必填）
  - （可选）`DEEPSEEK_API_KEY`
  ```bash
  node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"
  ```
- [ ] 记下后端域名，回填到 `.env.production` 的 `VITE_API_BASE_URL`，再跑一次：
  ```bash
  pnpm build && tcb hosting deploy dist -e <环境ID>
  ```

## 三、完成
浏览器打开静态站域名即可访问。完整命令与字段说明见同目录 `README.md`。
